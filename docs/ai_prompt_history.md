# AI Tool Usage and Prompt History

## Purpose
AI tools were used as development assistants during the CommerceClean
entity-resolution and deduplication project.

## Main assistance areas

1. Project architecture
   - Discussed Django application structure, models, and service separation.
2. Data validation and normalization
   - Explored validation rules, normalization strategies, and edge cases.
3. Duplicate detection
   - Discussed exact matching, probable matching, candidate generation,
     confidence scoring, and blocking.
4. Survivorship and merging
   - Reviewed field-level survivorship decisions, merge safety,
     transaction handling, and lineage.
5. Testing and debugging
   - Used AI assistance to investigate errors, improve test cases,
     and interpret test results.
6. Documentation and submission
   - Assisted with README structure, benchmark evidence, and
     reconciliation output packaging.

## Human review and validation

AI-generated suggestions were treated as proposals, not trusted output.
Implementation decisions were reviewed against the project requirements.
Automated tests and database inspection were used to validate behavior.

## Important note

This document summarizes the categories of AI assistance used.
It is not a verbatim transcript of every prompt or response.
